## Study design

All seven dependency-free tasks previously admitted by the protected evaluator are included, with two existing candidates per task. Four candidates come from the earlier timely cohort; ten are late diagnostic recoveries. The organizer knew historical candidate outcomes before this fixed-candidate study. This is not a held-out repair benchmark or an end-to-end repair-system comparison.

Generators received only original source, manifest, visible witness, and frozen C0, not candidates, fixed source, reference scores, or hidden tests. Each task-method used one GPT-5.2 request, a 600-second response deadline and a 24,000-character cap, with at most two concurrent requests. Schedule seed 20261004 is not a model sampling seed. Matched caps do not imply equal actual compute or test strength.

## Post-hoc parser sensitivity

After observing strict-format failures, one rule was selected: remove a single Markdown JSON fence only when it wraps the entire original response, then apply the unchanged exact-JSON parser and static safe-client checks. The rule applies symmetrically to every response from both methods, with the original 24,000-character cap enforced before normalization. No substring recovery, Rust edits, assertion changes, scene deletion, or new model calls are permitted.

The transformation and stopping rule were frozen before executing the two newly exposed programs, but after the strict study; this is not a confirmatory preregistration. Twelve byte-identical programs reuse the strict program file and existing execution records. Four additional executions (twelve process records) cover T03 fixed/B1/B2 and T05 fixed. T03 distinguishes B1 and B2; T05 still fails to compile with E0382 and both candidates receive ABSTAIN. No further interface adjustment was made.

## Provenance and package contents

This is an unsigned review derivative. In eleven process logs, only the original host toolchain-root prefix was replaced by `/toolchain`; the Rust library suffix, diagnostics, line, and column were retained. `derivation.json` records original and review hashes. Source, contract, prompt, response, and retained test bytes are unchanged.

Derived records contain original evidence/context/log hashes and new log hashes, but omit original signatures, host command paths, and service identifiers. Original signatures cannot authenticate the transformed logs. Original signed records and transport provenance remain in a restricted archive. Even original per-run signatures are locally generated and have no external issuer or attestation trust root.

Complete source snapshots are retained because their file inventories are bound to archived execution contexts. This includes upstream tests, benchmarks, CI files, lockfiles, metadata, and licenses. Empty process logs are retained as evidence of executions with no output.

Identical strict/normalized test copies are stored once. Protocol implementation and test source remain byte-identical to the original pilot; their CSV and JSON reports are regenerated by the test script rather than archived. `run_checks.py` executes this script in a temporary copy; the README shows how to retain the reports. Manuscript and presentation files are not included in this repository.

## Not reproduced by this package

The paper also describes earlier constructed Rust mutants, historical release controls, process-boundary checks and model-repair batches. Their original signed execution and transport archives are not included here. The finite protocol model is included, but that is not a substitute for those historical Rust runs. This package therefore supports the main fixed-candidate comparison and the protocol model, not every empirical layer in the manuscript.

Model regeneration is not exactly reproducible: an immutable provider snapshot, sampling parameters and token-cost record are unavailable. Reference labels lack independent expert adjudication. Package hashes establish integrity relative to the manifest, not independent authenticity. Removal of known organizer host identifiers does not provide a general anonymity guarantee.
